Excavation Audio Starter Pack
Procedural retro/chiptune WAV prototype assets.

SFX: dig, rock break, gold pickup, gem pickup, super pick,
sticky smell, beast growl/dig, footsteps, caught, level complete,
game over, purchase, UI click.

Music: menu, gameplay, chase loops.

These are prototype assets intended to be wired into macroquad and
can later be replaced with authored final audio while keeping the
same event names.
